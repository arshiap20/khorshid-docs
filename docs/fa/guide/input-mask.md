# ماسک ورودی و قالب‌بندی

پیکری که به یک `<input>` متصل است، متن کاربر را همان‌طور که تایپ می‌کند قالب‌بندی می‌کند و تاریخ‌ها را با قالبی قابل‌تنظیم نمایش می‌دهد. این صفحه ماسک هوشمند، توکن‌های قالب، قالب نمایش سفارشی، جایگزین‌کردن ماسک با تابع خودتان و پارس متن بیرون از پیکر را توضیح می‌دهد.

## ماسک ورودی هوشمند {#the-smart-input-mask}

در حالت تکی و با واحد پیش‌فرضِ روز، ورودی متصل یک ماسک هوشمند می‌گیرد. بدون جداکننده رقم بزنید، ارقام فارسی paste کنید، یا وسط مقدار چیزی را پاک کنید:

<Demo :controls="['value']" placeholder="۱۴۰۵/۰۱/۰۱" caption="۱۴۰۵۰۱۰۱ را تایپ کنید — جداکننده‌ها همان‌طور که پیش می‌روید ظاهر می‌شوند." />

کارهایی که ماسک انجام می‌دهد:

- **جداکننده‌ها را خودش درج می‌کند** بر اساس قالب (توکن‌های عددی `YYYY MM DD M D`؛ پیش‌فرض، قالب نمایش لوکال است). فقط رقم بزنید تا `/` ظاهر شود.
- **هر نوع رقمی را می‌پذیرد**: فارسی (۰–۹)، عربی-هندی (٠–٩) و لاتین. متن ماسک‌شده با ارقام لوکال نمایش داده می‌شود.
- **مقدارهای ناممکن را حین تایپ اصلاح می‌کند**: ماه را به ۱ تا ۱۲ و روز را به طول ماه در تقویم فعال محدود می‌کند (اسفند در سال کبیسه ۳۰ روز دارد).
- **مکان‌نما را سر جایش نگه می‌دارد** و حذف را تشخیص می‌دهد؛ پس ویرایش وسط مقدار درست کار می‌کند.
- **هرگز خطا نمی‌دهد**، هرچه تایپ یا paste شود.
- **هنگام blur** متن را به مقدار قالب‌بندی‌شده تبدیل می‌کند.
- **مقدار را ثبت می‌کند** وقتی متن یک تاریخ کامل، معتبر و مجاز باشد (`change` با source برابر `'input'`). تاریخِ ردشده رویداد `error` را صادر می‌کند و ورودی کلاس `.sdp-input--invalid` را می‌گیرد.

در حالت‌های range و multiple، و با [واحد](./selection-units) هفته، ماه یا سال، ورودی فقط‌خواندنی است: مقدار قالب‌بندی‌شده را نشان می‌دهد و با فوکوس پیکر را باز می‌کند. [ورودی طبیعی](./natural-input) فیلد را در همهٔ حالت‌ها قابل‌ویرایش می‌کند. برای خاموش‌کردن ماسک از `inputMask: false` استفاده کنید.

## استفادهٔ مستقل از ماسک {#using-the-mask-on-its-own}

ماسک یک تابع خالص است. این تابع یک آبجکت `Locale` لازم دارد، نه کلید لوکال:

```js
import { maskDateInput, faIR } from 'khorshid/headless'

const { text, complete, valid } = maskDateInput('14050101', { locale: faIR })
// text: '۱۴۰۵/۰۱/۰۱', complete: true, valid: true
```

برای حفظ مکان‌نما و تشخیص حذف، `caret` و `previous` (آخرین متن ماسک‌شده) را هم بدهید. برای پیدا کردن لوکال با کلید، از `getLocale('fa-IR')` استفاده کنید.

## توکن‌های قالب {#format-tokens}

قالب‌بندی و پارس یک مجموعه توکن مشترک دارند. گزینهٔ `format`، قالب‌های نمایش لوکال‌ها و `PlainDate.format()` همه از آن‌ها استفاده می‌کنند:

| توکن | معنی | `en-US`، ۱۴۰۵/۰۱/۰۱ | `fa-IR`، ۱۴۰۵/۰۱/۰۱ |
|---|---|---|---|
| `YYYY` | سال ۴رقمی | `1405` | `۱۴۰۵` |
| `YY` | سال ۲رقمی | `05` | `۰۵` |
| `MMMM` | نام کامل ماه | `Farvardin` | `فروردین` |
| `MMM` | نام کوتاه ماه | `Far` | `فروردین` |
| `MM` | ماه ۲رقمی | `01` | `۰۱` |
| `M` | ماه | `1` | `۱` |
| `DD` | روز ۲رقمی | `01` | `۰۱` |
| `D` | روز | `1` | `۱` |
| `dddd` | نام کامل روز هفته | `Saturday` | `شنبه` |
| `ddd` | نام کوتاه روز هفته | `Sat` | `شنبه` |
| `dd` | کوتاه‌ترین نام روز هفته | `Sa` | `ش` |
| `[…]` | متن ثابت | `[Today:] YYYY/MM/DD` | `[امروز] YYYY/MM/DD` |

ارقام با مجموعهٔ ارقام لوکال نمایش داده می‌شوند. در الگوی ماسک فقط توکن‌های عددی (`YYYY MM DD M D`) معتبرند. مرجع کامل در [توکن‌های قالب](/fa/api/format-tokens) آمده است.

## قالب نمایش سفارشی {#custom-display-format}

```js
createDatePicker('#date', {
  locale: 'fa-IR',
  format: 'dddd D MMMM YYYY', // مثلاً شنبه ۱ فروردین ۱۴۰۵
})
```

همین قالب، متن `formatted` در هر [`DateValue`](/fa/api/events#datevalue) را هم که پیکر صادر می‌کند تعیین می‌کند.

## تابع ماسک سفارشی

وقتی ماسکِ مبتنی بر قالب کافی نیست (توکن‌های سفارشی، جداکننده‌های غیرمعمول، یا منطقی کاملاً متفاوت)، یک تابع `mask` بدهید. این تابع جای ماسک داخلی را می‌گیرد، متن خام فیلد و یک `MaskContext` کامل را دریافت می‌کند و یک `MaskResult` برمی‌گرداند. روی هر کلید اجرا می‌شود؛ پس هرگز نباید خطا بدهد.

```js
createDatePicker('#date', {
  locale: 'fa-IR',
  mask: (raw, { locale, format, calendar, caret, previous }) => {
    // ...منطق ماسک شما...
    return {
      text,               // چیزی که فیلد نمایش می‌دهد
      caret,              // موقعیت مکان‌نما داخل text
      parts: { year, month, day }, // گروه‌هایی که تا اینجا پر شده‌اند
      complete,           // همهٔ گروه‌ها پر شده‌اند؟
      valid,              // کامل است و یک تاریخ واقعی؟
    }
  },
})
```

خروجی از همان مسیر ثبتِ ماسک داخلی می‌گذرد: وقتی `complete` و `valid` باشد و `parts` یک تاریخ واقعی باشد، پیکر همان تاریخ را انتخاب می‌کند (`change` با `source: 'input'`) و `min`، `max` و `disabledDates` را مثل همیشه اعمال می‌کند. در غیر این صورت فیلد فقط متن تازه را نشان می‌دهد.

```ts
type MaskFn = (raw: string, context: MaskContext) => MaskResult

interface MaskContext {
  locale: Locale
  format: FormatPattern   // قالب نمایشِ نهایی
  calendar: CalendarId    // 'jalali' | 'gregorian' | 'hijri'
  caret: number | null
  previous: string        // آخرین متن ماسک‌شده، برای تشخیص حذف
}
```

اگر `mask` را ندهید، همان ماسک هوشمند پیش‌فرض به کار می‌رود.

## پارس {#parsing}

تابع `parseDate` هر جداکننده‌ای را می‌پذیرد (`/`، `-`، `.`، فاصله) و ارقام فارسی و عربی-هندی را پیش از پارس تبدیل می‌کند. این تابع هم مثل ماسک یک آبجکت `Locale` می‌گیرد:

```js
import { parseDate, faIR } from 'khorshid/headless'

parseDate('۱۴۰۵-۰۱-۰۱', { locale: faIR })  // PlainDate (جلالی ۱۴۰۵/۰۱/۰۱)
parseDate('1405.1.1',    { locale: faIR })  // همان تاریخ
```

داخل پیکر، متدهای `picker.core.format()`، `picker.core.parse()` و `picker.core.handleInput()` خودشان از لوکال و قالب فعال پیکر استفاده می‌کنند.
