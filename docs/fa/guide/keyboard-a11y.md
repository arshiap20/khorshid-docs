# کیبورد و دسترس‌پذیری

هر پیکر خورشید بدون هیچ تنظیمی با کیبورد کار می‌کند و صفحه‌خوان‌ها آن را درست می‌خوانند. این صفحه کلیدها، ساختار ARIA و تأثیر لوکال‌های راست‌به‌چپ بر رفتار پیکر را فهرست می‌کند.

## امتحان کنید {#try-it}

روی یک روز کلیک کنید و بعد کلیدهای جهت‌نما را بزنید. در لوکال‌های RTL، کلیدهای `←` و `→` جابه‌جا می‌شوند تا از جهت خواندن پیروی کنند:

## نمای روزها {#days-view}

| کلید | عمل |
|---|---|
| `←` / `→` | روز قبل / بعد، جابه‌جاشده در لوکال‌های RTL |
| `↑` / `↓` | هفتهٔ قبل / بعد |
| `PageUp` / `PageDown` | ماه قبل / بعد |
| `Shift+PageUp` / `Shift+PageDown` | سال قبل / بعد |
| `Home` / `End` | ابتدا / انتهای هفته |
| `Enter` / `Space` | انتخاب روزِ فوکوس‌شده |
| `Escape` | بستن پیکر |

## نمای ماه‌ها و سال‌ها {#months-and-years-views}

کلیدهای جهت‌نما یکی‌یکی یا سه‌تاسه‌تا جابه‌جا می‌شوند (جدول ۳ ستون دارد) و از خانه‌های غیرفعال رد می‌شوند؛ `Enter` هم انتخاب می‌کند. برای رفتن به این نماها روی ماه یا سالِ سرصفحه کلیک کنید.

کلیدهایی که در سرصفحه، پاصفحه، ردیف [میان‌برها](./shortcuts-and-limits) یا ردیف ساعت زده می‌شوند رفتار عادی خودشان را دارند؛ فقط جدول روزها کلیدهای پیمایش را مدیریت می‌کند. پیکرهای vanilla، React و Vue یک پیاده‌سازی مشترک برای کیبورد دارند؛ پس دقیقاً یکسان رفتار می‌کنند.

## صفحه‌خوان و فوکوس {#screen-readers-and-focus}

- پنجرهٔ popup یک `role="dialog"` با `aria-modal="false"` است؛ پنجره‌های bottom sheet و modal مقدار `aria-modal="true"` دارند و تا وقتی باز هستند فوکوس را داخل خودشان نگه می‌دارند.
- با بسته شدن overlay، فوکوس به فیلدی برمی‌گردد که آن را باز کرده بود.
- جدول روزها از نقش‌های grid در ARIA و roving tabindex استفاده می‌کند: کل جدول یک توقف Tab است و کلیدهای جهت‌نما فوکوس را درون آن جابه‌جا می‌کنند. نماهای ماه‌ها و سال‌ها هم همین‌طورند.
- سرستون‌های روز هفته سلول‌هایی با `role="columnheader"` درون جدول‌اند؛ پس هر روز همراه ستونش خوانده می‌شود.
- نام دسترس‌پذیر هر روز، تاریخ کامل و بومی‌شدهٔ آن است. تاریخ [تقویم دوم](./secondary-calendar)، دلیل [غیرفعال بودن](./shortcuts-and-limits#disabled-dates-with-a-reason) روز و برچسب markهای [پلاگین‌ها](./plugins)، مثل نام تعطیلی‌ها، هم به آن اضافه می‌شوند.
- تغییر ماه و سال از طریق یک ناحیهٔ `aria-live` پنهان اعلام می‌شود.
- دکمه‌های پیمایش برچسب‌های بومی دارند: ماه قبل/بعد در نمای روزها، و سال قبل/بعد در نماهای ماه‌ها و سال‌ها.
- انیمیشن‌ها از `prefers-reduced-motion` پیروی می‌کنند. برای خاموش‌کردن آن‌ها برای همه، `animate: false` را بدهید.

[فیلد تاریخ](./date-field) نقشهٔ کلیدهای خودش را دارد که در صفحهٔ خودش آمده است.

## RTL {#rtl}

جهت از لوکال می‌آید و تنظیم جداگانه‌ای ندارد. پیکر `fa-IR` راست‌به‌چپ چیده می‌شود، کلیدهای جهت‌نمای افقی را جابه‌جا می‌کند و لبه‌های بازه را متناسب با آن مرتب می‌کند؛ پیکر `en-US-gregorian` چپ‌به‌راست است. تعویض لوکال در زمان اجرا همهٔ این‌ها را فوراً به‌روز می‌کند.

ساختار کامل DOM، نقش‌های ARIA و نقشهٔ کیبورد در [`CONTRACT.md`](https://github.com/khorshid/khorshid/blob/main/packages/dom/CONTRACT.md) پکیج مشخص شده است.
