# واحدهای انتخاب

گزینهٔ `mode` تعیین می‌کند کاربر چند چیز انتخاب کند (یکی، یک بازه، چندتا) و `unit` تعیین می‌کند
هر انتخاب چیست: یک روز، یک هفته، یک ماه یا یک سال. این دو از هم مستقل‌اند؛ پس «بازه‌ای از
ماه‌ها» یا «چند هفتهٔ جدا از هم» فقط ترکیبی از این دو گزینه است. برای ساختن انتخابگر هفته، ماه
و سال این صفحه را بخوانید.

## چهار واحد {#the-four-units}

| `unit` | هر کلیک چه چیزی را انتخاب می‌کند | پیکر با این نما باز می‌شود |
|---|---|---|
| `'day'` (پیش‌فرض) | یک روز | نمای روزها |
| `'week'` | کل هفتهٔ روزِ کلیک‌شده، بر اساس `weekStart` | نمای روزها |
| `'month'` | یک ماه | نمای **ماه‌ها** |
| `'year'` | یک سال | نمای **سال‌ها** |

## انتخاب هفته {#week-picker}

```js
createDatePicker('#week', { locale: 'fa-IR', unit: 'week' })
```

<Demo inline :options="{ unit: 'week' }" :controls="['value', 'form']" caption="unit: 'week'. با hover کل هفته پیش‌نمایش داده می‌شود و کلیک، شنبه تا جمعه را انتخاب می‌کند (fa-IR)." />

وقتی نشانگر روی یک روز می‌رود، کل هفتهٔ آن پیش‌نمایش داده می‌شود و با کلیک انتخاب می‌شود.
هفته از نخستین روز هفته در لوکال شروع می‌شود (برای `fa-IR` شنبه و برای `en-US-gregorian`
یکشنبه)، مگر اینکه با `weekStart` آن را تغییر داده باشید.

## انتخاب ماه {#month-picker}

```js
createDatePicker('#month', { locale: 'fa-IR', unit: 'month' })
```

پیکر با نمای ماه‌ها باز می‌شود و کلیک روی یک ماه، به‌جای رفتن به نمای روزها، انتخاب را
**نهایی (commit)** می‌کند. سالِ بالای پنل همچنان برای ورق‌زدن بین سال‌هاست.

## شکل مقدار {#what-the-value-looks-like}

هر مورد انتخاب‌شده به‌صورت **نخستین روزِ دورهٔ خودش** ذخیره می‌شود و
[`DateValue`](/fa/api/events#datevalue) یک فیلد `end` هم پیدا می‌کند که آخرین روز همان دوره
است. متن `formatted` هم کل دوره را توصیف می‌کند:

```js
const picker = createDatePicker('#month', { locale: 'fa-IR', unit: 'month' })

picker.on('change', ({ value }) => {
  const { date } = value                 // حالت تکی
  date.jalali       // { year: 1405, month: 3, day: 1 }
  date.end.jalali   // { year: 1405, month: 3, day: 31 }
  date.formatted    // 'خرداد ۱۴۰۵'
  picker.core.getFormValue() // '2026-05-22/2026-06-21'
})
```

| واحد | `formatted` (fa-IR) | مقدار فرم |
|---|---|---|
| `week` | `۱۴۰۵/۰۱/۱۵ تا ۱۴۰۵/۰۱/۲۱` | `2026-04-04/2026-04-10` |
| `month` | `خرداد ۱۴۰۵` | `2026-05-22/2026-06-21` |
| `year` | `۱۴۰۳` | `2024-03-20/2025-03-20` |

`setValue` (و همین‌طور `value` اولیه) هر روزی را به دورهٔ خودش می‌برد؛ یعنی اگر `'2026-07-19'`
را به یک پیکر ماهانه بدهید، کل ماه ژوئیه (یا تیر) انتخاب می‌شود.

## ترکیب با حالت‌ها {#combining-with-modes}

`unit` با همهٔ [حالت‌های انتخاب](./selection-modes) کار می‌کند:

```js
// بازه‌ای از ماه‌ها: از اردیبهشت تا مرداد
createDatePicker('#quarter', { locale: 'fa-IR', unit: 'month', mode: 'range' })

// چند هفتهٔ مستقل از هم
createDatePicker('#shifts', { locale: 'fa-IR', unit: 'week', mode: 'multiple' })
```

<Demo inline mode="range" :options="{ unit: 'month' }" :controls="['value']" caption="unit: 'month' همراه با mode: 'range'. ماه‌های میان دو سر بازه هم برجسته می‌شوند." />

بازهٔ ماهانه یا هفتگی از نخستین روزِ اولین دوره تا آخرین روزِ آخرین دوره را در بر می‌گیرد:
`اردیبهشت ۱۴۰۵ تا مرداد ۱۴۰۵`. خانه‌های ماه و سال هم درست مثل خانه‌های روز، `rangeStart`،
`rangeEnd` و `inRange` دارند (`.sdp__month--range-start`، `--in-range` و …).

## نکته‌ها {#notes}

- `min` / `max` همچنان اعمال می‌شوند. ماه یا سالی که **کاملاً** بیرون از این محدوده باشد
  غیرفعال است؛ اما اگر فقط بخشی از آن با محدوده هم‌پوشانی داشته باشد، قابل انتخاب است.
- [میان‌برها](./shortcuts-and-limits) واحد انتخاب را می‌شناسند: `shortcuts: true` روی پیکر
  ماهانه چیپ‌های «این ماه»، «ماه گذشته» و «ماه آینده» را نشان می‌دهد.
- روی یک `<input>`، هر واحدی غیر از روز فیلد را فقط‌خواندنی می‌کند: فیلد دورهٔ
  قالب‌بندی‌شده را نشان می‌دهد و فقط پیکر را باز می‌کند.
- واحد هنگام ساخت پیکر تعیین می‌شود و بعداً عوض نمی‌شود؛ با `picker.core.getUnit()` می‌توانید
  آن را بخوانید. ریشهٔ پنل هم برای استایل‌دهی ویژگی `data-unit` (`day`، `week`، `month` یا `year`) را دارد.
