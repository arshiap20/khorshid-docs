# توکن‌های قالب

واژگان توکنی که پشت گزینهٔ `format`، قالب‌های لوکال، `PlainDate.format()` و فیلد تاریخ است. نام‌ها و ارقام از لوکال می‌آیند، پس یک الگو در هر زبان و تقویمی کار می‌کند.

## توکن‌های تاریخ {#date-tokens}

| توکن | معنی | `en-US`، ۱۴۰۵/۰۱/۰۱ | `fa-IR`، ۱۴۰۵/۰۱/۰۱ |
|---|---|---|---|
| `YYYY` | سال چهاررقمی | `1405` | `۱۴۰۵` |
| `YY` | سال دورقمی | `05` | `۰۵` |
| `MMMM` | نام کامل ماه | `Farvardin` | `فروردین` |
| `MMM` | نام کوتاه ماه | `Far` | `فروردین` |
| `MM` | ماه دورقمی | `01` | `۰۱` |
| `M` | ماه | `1` | `۱` |
| `DD` | روز دورقمی | `01` | `۰۱` |
| `D` | روز | `1` | `۱` |
| `dddd` | نام کامل روز هفته | `Saturday` | `شنبه` |
| `ddd` | نام کوتاه روز هفته | `Sat` | `شنبه` |
| `dd` | کوتاه‌ترین نام روز هفته | `Sa` | `ش` |
| `[…]` | متن ثابت، بی‌تغییر کپی می‌شود | `[Nowruz] YYYY` ← `Nowruz 1405` | `[نوروز] YYYY` ← `نوروز ۱۴۰۵` |

هر دو لوکال بالا تقویم جلالی دارند؛ `en-US` همان جلالی با برچسب‌های انگلیسی است. متنی که توکن نیست هم کپی می‌شود، ولی کلمه‌ها را در کروشه بگذارید تا حروفشان هرگز توکن خوانده نشوند.

## توکن‌های ساعت {#time-tokens}

`format` فیلد تاریخ و تابع کمکی `formatTime` توکن‌های ساعت را هم می‌خوانند. متن ساعت خود پیکر ثابت است: `HH:mm`، `HH:mm:ss`، `hh:mm A` یا `hh:mm:ss A`، بسته به `TimeOptions`.

| توکن | معنی | مثال |
|---|---|---|
| `HH` / `H` | ساعت ۰ تا ۲۳، با صفر / بدون صفر | `09` / `9` |
| `hh` / `h` | ساعت ۱ تا ۱۲، با صفر / بدون صفر | `09` / `9` |
| `mm` / `m` | دقیقه، با صفر / بدون صفر | `05` / `5` |
| `ss` / `s` | ثانیه، با صفر / بدون صفر | `07` / `7` |
| `A` / `a` | AM/PM، حروف بزرگ / کوچک (در فارسی `ق.ظ` / `ب.ظ`) | `PM` / `pm` |

## هر توکن کجا کار می‌کند {#where-each-token-works}

| استفاده‌کننده | توکن‌ها |
|---|---|
| گزینهٔ `format`، `core.format()`، `PlainDate.format()`، `formatDate()` | همهٔ توکن‌های تاریخ. |
| `parse()`، `parseDate()`، `submitInput()` | فقط توکن‌های عددی تاریخ: `YYYY`، `YY`، `MM`، `M`، `DD`، `D`. قالبی که نام ماه یا روز هفته دارد دوباره خوانده نمی‌شود؛ برای پذیرفتن نام‌های تایپ‌شده `naturalInput` را روشن کنید. |
| ماسک ورودی (`maskDateInput`، `inputMask`) | `YYYY`، `MM`، `DD`، `M`، `D`. |
| `format` فیلد تاریخ | توکن‌های تاریخ و ساعت. `MMMM` و `MMM` ماه را با نام نشان می‌دهند، `YY` مثل `YYYY` خوانده می‌شود، توکن‌های روز هفته کنار گذاشته می‌شوند، و توکن‌های ساعت، ساعت را روشن می‌کنند. |

## قواعد خواندن متن {#parsing-rules}

- هر کدام از `/`، `-`، `.` یا فاصله گروه‌ها را جدا می‌کند، هر جداکننده‌ای که قالب داشته باشد.
- ارقام فارسی و عربی-هندی اول به لاتین تبدیل می‌شوند و نشانه‌های کنترل جهت حذف می‌شوند.
- `YY` به قرن جاری تقویم مقصد برگردانده می‌شود.
- نتیجه باید تاریخی واقعی در آن تقویم باشد، وگرنه خروجی `null` است.

## مثال‌ها {#examples}

```js
import { PlainDate, faIR, enUS } from 'khorshid/headless'

const d = new PlainDate('jalali', 1405, 1, 1)

d.format('YYYY/MM/DD', faIR)        // '۱۴۰۵/۰۱/۰۱'
d.format('dddd D MMMM YYYY', faIR)  // 'شنبه ۱ فروردین ۱۴۰۵'
d.format('D MMM YY', enUS)          // '1 Far 05'
d.format('[Nowruz] YYYY', enUS)     // 'Nowruz 1405'
```

قالب نمایش یک پیکر را با گزینهٔ `format` تعیین کنید:

```js
createDatePicker('#date', { locale: 'fa-IR', format: 'dddd D MMMM YYYY' })
```
